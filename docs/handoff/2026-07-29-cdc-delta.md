## 다음 사람이 할 일
- 고객과 **델타 CSV 계약** 확정: 1:1/expand=델타(`__op`), join/union=full 스냅샷. 하드삭제 유무·LogMiner op 출력 여부.
- (선택) Oracle 타깃 병합(`MERGE INTO`), 대용량 join의 "진짜 증분"(AS-IS mirror+변경키 재조인).

## 함정 / 결정 이력
- **`__op` 없으면 full 재파생**: Transform 이 `__op` passthrough한 tobe_ 만 Load가 merge. join/union+`__op` → fail-fast(조인 델타 불가). join/union+full스냅샷 → 정상 변환 후 truncate+reload.
- **델타 버튼 게이트 = "non-delta full run이 한 번이라도 success"**(불변 이력). 초기엔 run-readiness(최신 run success)로 걸었으나, **델타 run 1회 실패 시 최신=failed→버튼 잠김→초기적재 재실행 강요** 문제로 교체. (`ExecutionPage.initialLoadDone`)
- **진행바**: `buildStagesFromStageViews`가 run의 실제 스테이지만 렌더 → 델타=5단계(100%), 일반=8단계.
- **exhaustive switch 3곳**(RunService maybeAdvancePhase/resolveSnapshotId, QuarantineAckService) + run_type CHECK 마이그레이션 = enum 추가 시 동시 수정.
- 델타는 audit/verify/validation 생략(전수 검증 비현실) — 정합성은 컷오버 reconciliation.

## 안 한 것 (의도적으로)
- Oracle 타깃 delta merge(PG 타깃 전용).
- join/union 대용량의 증분 조인(현재는 full 재파생 — 소스가 작은 참조 테이블 전제).
- join full 재파생의 truncate-후-실패 창(재실행으로 복구, 타깃이 컷오버 전엔 비운영본이라 무해).
- expand "채널 값만 제거"(update→null) orphan edge case.
