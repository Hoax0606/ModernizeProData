# 2026-05-26 — mask-phone-group-policy (Suhyun Jin)

`mask_phone` UDF 의 정책을 일본 dial-plan 에 맞게 조정.

## 한 일

- **`MaskPhoneUdf.java` 정책 변경**: "앞 3 + 뒤 4 보존" → "구분자 있으면 **첫 그룹 + 뒤 4**, 없으면 앞 3 + 뒤 4".
  - 이전: `03-1234-5678` → `03*-****-5678` (어색)
  - 현재: `03-1234-5678` → `03-****-5678` (자연)
  - `045-123-4567` → `045-***-4567`, `090-1234-5678` → `090-****-5678` 모두 일본 표준 마스킹 표기와 일치
  - 구분자 없는 `09012345678` 케이스는 기존 정책 유지 (앞 3 + 뒤 4)

## 함정 / 결정 이력

- 일본 dial-plan 의 첫 그룹 자릿수가 가변 (`03` / `045` / `090`) 이라 고정 "앞 3 자" 정책으로는 짧은 prefix 케이스 표현 못함. `firstSepIdx` 감지 후 분기로 해결.
- `1234567` 같이 구분자 없는 7 자 케이스는 첫 그룹이 없으니 `***4567` — 의도된 동작.
- Notion `UDF.java` 페이지 §6 의 예시 표도 새 정책으로 갱신.
